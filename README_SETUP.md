## 04 &nbsp; Bring the snake to life.

The contribution snake follows your activity in a matching sage palette, with separate light and dark versions.

1. Open **Actions → Contribution Snake** in your repository. Enable Actions if prompted.
2. Select **Run workflow** on the default branch. Uploading the workflow to `main` or `master` also triggers it.
3. Wait for **Generate and publish snake** to complete, then refresh your profile.

The workflow creates the `output` branch and publishes both animation files automatically. It runs daily at **05:17 Maldives time (00:17 UTC)**, though GitHub can delay scheduled runs. No manual output branch setup or GitHub Pages configuration is needed.

### If something doesn't appear

| What you see | What to check |
| :--- | :--- |
| **Header or footer missing** | Upload `assets/hero.png` and `assets/footer.png` alongside the README. The SVG files alone do not replace the PNGs used by the profile. |
| **Images missing in the IDE** | Open the Markdown preview, with the complete profile folder open in your workspace. The links use relative paths. |
| **Old banner still showing** | Confirm the updated PNG was committed, then reload the preview or profile. |
| **Snake missing** | Check that the first workflow run succeeded and that the raw image URLs use your actual repository name. |
| **Workflow publishing fails with 403** | Check repository or organization Actions policy allows the workflow's `contents: write` permission. |
